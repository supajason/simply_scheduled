# Changelog

## 0.2.0

* Renamed displayed add-on and panel title to Scheduler; preserved add-on slug for upgrade compatibility.
* Removed support for scripts, scenes, automations and media players; backed up the original schedule file when migrating unsupported schedules.
* Added device-specific controls for lights, climate, fans, covers and humidifiers.
* Added searchable device visibility settings and exclusion persistence.
* Added separate settings to group device selection and the schedule list by type.
* Simplified entity labels and moved entity IDs to selection details / visibility settings.
* Replaced the three-dot delete action with a bin icon.

## 0.1.0

Initial experimental release with a responsive scheduler interface, weekly time scheduling, Home Assistant service calls and persistent schedules.
